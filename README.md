## About

**Computing Nexus** is an open educational documentation project focused on modern scientific computing and high-performance software development.

The goal is to provide clear, practical, and well-structured learning material covering both the theoretical foundations and real-world implementation of computational science.

Whether you are a student beginning your HPC journey or a researcher developing large-scale scientific software, this documentation aims to bridge the gap between algorithms and efficient implementations.

---

## Topics Covered

The documentation includes tutorials, examples, and best practices on topics such as:

* Modern Fortran
* High-Performance Computing (HPC)
* Parallel Programming

  * OpenMP
  * MPI
  * Coarrays
  * `DO CONCURRENT`
* Numerical Methods
* Scientific Computing
* Performance Optimization
* Compiler Optimization
* Memory Hierarchy
* GPU Computing
* FFT Algorithms
* Phase-Field Modeling
* Computational Materials Science
* Machine Learning for Scientific Computing
* Physics-Informed Neural Networks (PINNs)
* AI for Scientific Simulations
* Software Engineering for Scientific Applications
* Reproducible Research

---

## Project Goals

This documentation is designed to

* explain difficult HPC concepts in a simple way,
* provide practical code examples,
* emphasize performance-aware programming,
* promote modern Fortran best practices,
* connect scientific computing with emerging AI techniques, and
* serve as a long-term reference for researchers and engineers.

## Why Computing Nexus?

Modern computational science sits at the intersection of mathematics, algorithms, software engineering, and high-performance computing.

Computing Nexus brings these areas together into one continuously evolving knowledge base, making it easier to learn, apply, and share best practices for building efficient scientific software.
